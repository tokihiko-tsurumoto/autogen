# [AutoGen](https://microsoft.github.io/autogen/stable//index.html)

A framework for building AI agents and applications.

## [Magentic-One CLI](https://microsoft.github.io/autogen/stable//user-guide/agentchat-user-guide/magentic-one.html)

A console-based multi-agent assistant for we and file-based tasks.

## [Studio](https://microsoft.github.io/autogen/stable//user-guide/autogenstudio-user-guide/index.html)

An app for prototyping and managing agents without writing code.

## [AgentChat](https://microsoft.github.io/autogen/stable//user-guide/agentchat-user-guide/quickstart.html)

A programming framework for building conversational single and multi-agent applications.

## [Core](https://microsoft.github.io/autogen/stable//user-guide/core-user-guide/quickstart.html)

An event-driven programming framework for building scalable multi-agent AI systems.

## [Extensions](https://microsoft.github.io/autogen/stable//user-guide/extensions-user-guide/discover.html)

Implementations of Core and AgentChat components that interface with external services or other libraries.
